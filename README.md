# README

## WkDraw

WkDraw is a personal project, a simple application designed to aid in learning kanji while using WaniKani. This tool combines kanji recognition, animation, and visualization to enhance the kanji learning experience. 

### **Features**
- Kanji recognition with real-time feedback.
- Animation of kanji stroke orders using KanjiVG and KanjiVGAnimate.

### **How to Use**
To run the application locally:
1. Clone the repository: `git clone https://github.com/your-username/wkdraw.git`
2. Navigate to the project directory.
3. Install dependencies if required (e.g., Node.js, npm).
4. Start the application by following the instructions in the `SETUP.md` file.
